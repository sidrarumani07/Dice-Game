# 🎲 Dicee Game

A simple **Dice Game web app** built using **HTML, CSS, and JavaScript**.  
Refresh the page to roll two dice and see which player wins!  

---

## 🚀 Features  
- Simulates rolling two dice using random number generation.  
- Displays dice images dynamically based on the roll outcome.  
- Declares the winner (Player 1, Player 2, or Draw).  
- Fun and lightweight browser game.  

---

## 🛠️ Tech Stack  
- **HTML5** – Structure of the game.  
- **CSS3** – Styling.  
- **JavaScript (Vanilla JS)** – Game logic and randomness.  

---

## 🎮 How to Play  
1. Open the game in your browser.  
2. Refresh the page to roll the dice.  
3. The higher number wins! 🎉  

---

## 📂 Project Structure  
```
📦 Dicee-Game
├── dicee.html       # Main HTML file
├── styles.css       # Styling
├── index.js         # JavaScript game logic
├── images/          # Dice face images (dice1.png - dice6.png)
```

---

## ▶️ How to Run  
1. Clone this repository:  
   ```bash
   git clone https://github.com/your-username/dicee-game.git
   cd dicee-game
   ```
2. Open `dicee.html` in your browser.  
3. Play the game 🎲
